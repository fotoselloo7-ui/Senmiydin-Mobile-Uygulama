# İçerik / yaş derecelendirme anketi hazırlığı

Denetim: 9 Kasım 2026. Bu belge kesin IARC veya Apple yaş derecesi belirlemez. Sonucu mağaza anketi, bölge ve inceleme belirler. Uygulamadaki **18 minimum kayıt yaşı** ayrı bir ürün kuralıdır; mağazanın hesapladığı derecenin yerine geçmez.

| Anket konusu | Kod temelli cevap önerisi / açıklama |
|---|---|
| UGC / kullanıcı paylaşımı | Evet; metin, fotoğraf, yorum ve ortak hikâye |
| Kullanıcı etkileşimi / özel mesaj | Evet; kullanıcı adıyla keşif, mesaj isteği ve kabul edilen sohbet |
| Konum / yakın keşif | Evet; opt-in cihaz konumu, yaklaşık mesafe, manuel şehir ve geçmiş eşleşmesi; kesin GPS public değil |
| Fotoğraf yükleme | Evet; video yükleme yok |
| Anonim içerik | İsteğe bağlı anonim public post var; sistem sahibi bilir. Rastgele anonim sohbet/Chatroulette ürünü yok |
| Reklam / satın alma / abonelik | Hayır; ilgili SDK/akış yok |
| Para ile kumar / simüle kumar / loot box | Ürün mekaniği yok |
| Şiddet, korku, cinsellik, çıplaklık, küfür, madde/alkol referansı | Uygulamanın editoryal teması/özelliği değildir. UGC metin/fotoğraflarında oluşma ihtimali vardır; “UGC’de asla yok” diye otomatik No doldurulmaz. Canlı moderasyon politikası/fiilî içerik sıklığına göre anket cevaplanır |
| Tıbbi/sağlık tavsiyesi | Özel ürün/SDK yok |
| Rehber veya mikrofon / sesli-görüntülü iletişim | Yok; Contacts gizlilik etiketi uygulama sosyal grafiğini kapsar |
| Serbest web erişimi | Gömülü genel web tarayıcı/WebView yok. Harita attribution, legal/destek ve mağaza bağlantıları OS tarayıcısında açılabilir; anketin güncel açıklamasına göre belirtilir |
| Report / block / parental controls | Report/block var; ebeveyn denetimi ürünü yok |
| Çocuklara yönelik ürün | Hayır; hedef yetişkinler. Social kategorisinin CSAE standardından yine muaf değildir |

## Gönderim sırası

Google Play’de Social, yetişkin hedef kitle ve gerçek kullanıcı etkileşimi işaretlenir; IARC sorularında gerçek UGC sıklığı/şiddeti operatör tarafından yanıtlanır. Apple’da UGC, messaging/chat ve location gibi güncel anket başlıkları dürüstçe doldurulur. UGC nedeniyle bir alt yaş derecesi garanti edilmez; Console gerekirse daha yüksek yaş sınırı/override değerlendirmesi gerçek ürün kuralıyla yapılır.

Güncel gerçek içerik örnekleri, moderasyon yanıt süresi, ülke hedefleri ve politika sahibi [GERÇEK BİLGİ GEREKLİ]. Onaylı içerik standardı olmadan şiddet/çıplaklık/küfür için belirli sıklık uydurulmadı.

Kaynaklar: [Google içerik derecelendirme](https://support.google.com/googleplay/android-developer/answer/9859655), [Apple yaş derecelendirme](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating/), [Google Social çocuk güvenliği](https://support.google.com/googleplay/android-developer/answer/14747720).
