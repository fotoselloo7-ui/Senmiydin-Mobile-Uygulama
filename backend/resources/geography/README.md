# Şehir sınırları ve atıf

cities.geojson, Türkiye'nin 81 il sınırını ve katalogda ayrı şehir olarak bulunan Alanya ilçe sınırını içerir. geoBoundaries gbOpen, 9469f09 revizyonundaki sadeleştirilmiş geometriler kullanılmıştır. Yalnızca isim/öncelik/bounding-box metadatası dönüştürülmüş; sınır koordinatları değiştirilmemiştir.

Bu dosya türetilmiş açık coğrafi veri kümesidir; ilgili paylaşım/atıf koşulları veriyle birlikte korunur. Uygulama kodunun lisansını değiştirmez. Resmî kadastro veya navigasyon verisi değildir. Sadeleştirilmiş sınırda belirsizlik veya kapsam dışında sonuç varsa şehir tahmin edilmez; manuel seçim sunulur. Resolver config/interface üzerinden değiştirilebilir; varsayılan hiçbir harici geocoding çağrısı yapmaz. Konumlar üçüncü tarafa iletilmez.
